# z2roN_Merge (엑셀 병합) v1.0.0
같은 열 구성의 엑셀(.xls/.xlsx/.csv, 첫 시트)을 올릴 때마다 SQLite 누적 파일에 덧붙이고 바로 보여주는 Windows 프로그램 (C# WinForms, .NET 8).
- 정렬(다중), 찾기, 업로드 미리보기/되돌리기, 업로드 내역 삭제, 중복 건너뛰기(선택), xlsx/csv 내보내기(104만 행 초과 시 분할)
- 빌드: .github/workflows/build.yml (GitHub Actions, 단일 exe)
